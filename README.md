# Weather Plugin

一个适应与Yunzai的天气插件

## 安装

在根目录选择一个来源执行：

**Gitee**

```bash
git clone https://gitee.com/cloud-star-dot/Weather-Plugin.git ./plugins/weather-plugin
```

**GitHub**

```bash
git clone https://github.com/yuxiri/Weather-Plugin.git ./plugins/weather-plugin
```

重启机器人后即可使用。请确认图片渲染器可用，并确保运行环境能够访问所选天气服务。插件不需要单独安装 npm 依赖。

## 常用指令

### 天气查询

| 指令 | 说明 |
| --- | --- |
| `#天气帮助` | 查看图片版帮助 |
| `#天气 北京` | 查询指定城市天气 |
| `#天气 东京,JP` | 为同名海外城市指定国家代码 |
| `#天气` | 查询默认城市；未绑定默认城市时使用订阅城市 |
| `#生活指数 北京` | 查看出行、穿衣、防晒等建议；城市可省略 |
| `#24小时预报 北京` | 查看未来逐小时天气；城市可省略 |
| `#天气对比 北京/上海` | 对比 2 至 4 个城市 |

国内地名只解析到地级市及以上层级。区县、县级市、街道和乡镇不能单独查询，请改用所属地级市。

### 默认城市和主题

| 指令 | 说明 |
| --- | --- |
| `#绑定城市 重庆` | 设置当前群或私聊的默认城市 |
| `#绑定城市` | 查看当前默认城市 |
| `#解绑城市` | 解除默认城市；之后优先使用订阅城市 |
| `#天气主题 ocean` | 切换天气卡片主题 |

可用主题：`ocean`、`sunset`、`night`。群内的默认城市和主题设置需要群主或管理员权限。

### 天气提醒和预警

| 指令 | 说明 |
| --- | --- |
| `#天气提醒` | 查看降雨、降雪提醒状态 |
| `#开启降雨提醒` / `#关闭降雨提醒` | 开启或关闭未来 24 小时降雨提醒 |
| `#开启降雪提醒` / `#关闭降雪提醒` | 开启或关闭未来 24 小时降雪提醒 |
| `#天气预警 北京` | 查询当前生效的气象预警；城市可省略 |
| `#开启预警提醒` / `#关闭预警提醒` | 开启或关闭气象预警推送 |

提醒使用当前会话的默认城市或订阅城市。预警提醒约每 15 分钟检查一次，每条新预警只推送一次；开启时已生效的预警会标记为已读，不会立即重复推送。群内提醒设置需要群主或管理员权限。

### 每日订阅和早晚报

| 指令 | 说明 |
| --- | --- |
| `#订阅天气 北京 07:30` | 每天按城市当地时间推送天气图片 |
| `#订阅天气 北京` | 每天当地时间 07:00 推送 |
| `#天气订阅` | 查看当前订阅 |
| `#取消天气订阅` | 取消每日天气推送 |
| `#设置天气早报 07:00` / `#设置天气晚报 20:00` | 设置每日简报时间 |
| `#关闭天气早报` / `#关闭天气晚报` | 关闭对应简报 |

每个群或私聊可设置一个天气订阅。群内订阅和简报设置需要群主或管理员权限。

## 天气数据源

发送 `#天气源` 查看当前来源，机器人主人可用以下命令切换全局天气来源：

```text
#切换天气源 bing
#切换天气源 open-meteo
#切换天气源 weatherapi
```

天气查询和每日推送会使用当前选择的来源。

| 来源 | 说明 |
| --- | --- |
| Bing 天气（MSN） | 默认来源，无需 API Key；从 MSN 天气页面读取预报和可用的预警数据 |
| Open-Meteo | 无需 API Key；提供天气预报和国内地名解析 |
| WeatherAPI.com | 需要 API Key；可提供天气数据，并作为气象预警备用来源 |

### 配置 WeatherAPI

先在 [WeatherAPI.com](https://www.weatherapi.com/signup.aspx) 申请 API Key，再私聊机器人发送：

```text
#设置天气API <API Key>
```

此命令仅机器人主人可用。密钥不会在回执中显示，也不会通过群聊命令保存。也可以设置环境变量 `WEATHERAPI_KEY`，或在 `data/weather-panel/settings.json` 中配置：

```json
{
  "source": "weatherapi",
  "weatherApiKey": "YOUR_API_KEY"
}
```

Bing/MSN 预警数据不可用时，已配置的 WeatherAPI 密钥可用于查询备用预警。预警类型与覆盖范围取决于数据源。

## 数据与文件

- 国内地名由 Open-Meteo 地理编码服务解析，并按地名层级过滤；海外城市可使用 Open-Meteo，未匹配时回退至 Photon。
- 同名海外城市可通过国家代码消歧，例如 `东京,JP`、`巴黎,FR`。
- 地理编码结果缓存 90 天。Photon 公共服务可能限流或暂时不可用。
- 天气卡片会标注天气数据来源；使用 Photon 解析的地点会附带 OpenStreetMap 署名。
- 订阅记录保存在 `data/weather-panel/subscriptions.json`。
- 默认城市、主题和提醒设置保存在 `data/weather-panel/preferences.json`。
- 数据源设置保存在 `data/weather-panel/settings.json`。
- `resources/` 包含天气卡片和帮助图片模板。
