# Weather Plugin

Weather Plugin 是一款适用于 Yunzai 的天气插件，支持实时天气、逐小时预报、生活指数、气象预警、降雨降雪提醒和定时天气推送。插件提供 Bing（MSN）、Open-Meteo、WeatherAPI 三种天气数据源，以及多种天气卡片主题。

## 功能特色

- 实时天气与多日预报、24 小时逐小时天气
- 生活指数与多城市天气对比
- 气象预警查询及新预警提醒
- 降雨、降雪提醒
- 每日天气订阅、天气早报与晚报
- 默认城市绑定
- `ocean`、`sunset`、`night` 三种主题
- Bing（MSN）、Open-Meteo、WeatherAPI 三种数据源

## 安装

在机器人项目根目录选择一个来源执行：

```bash
# Gitee
git clone https://gitee.com/cloud-star-dot/Weather-Plugin.git ./plugins/weather-plugin

# GitHub
git clone https://github.com/yuxiri/Weather-Plugin.git ./plugins/weather-plugin
```

安装后重启机器人。项目的 `package.json` 声明 Node.js `>=23.11`；插件不包含需要单独安装的 npm 依赖。请确认运行环境的图片渲染器可用，并能访问所选天气服务。

## 快速开始

```text
#天气 北京
#24小时天气 北京
#天气预警 北京
#绑定城市 重庆
#天气
#天气帮助
```

指令前的 `#` 可以省略。绑定默认城市后，`#天气` 可直接查询；未绑定时，如果当前会话已订阅天气，也会使用订阅城市。

## 常用指令

### 天气查询

| 指令 | 说明 |
| --- | --- |
| `#天气 北京` | 查询指定地点天气 |
| `#24小时天气 北京` | 查看逐小时预报 |
| `#生活指数 北京` | 查看生活指数 |
| `#天气对比 重庆/北京` | 对比 2 至 4 个城市 |
| `#天气预警 北京` | 查询地点或行政区域的生效预警 |

### 城市与主题

| 指令 | 说明 |
| --- | --- |
| `#绑定城市 重庆` | 设置默认城市 |
| `#解绑城市` | 解除默认城市 |
| `#天气主题 ocean` | 切换卡片主题；可选 `ocean`、`sunset`、`night` |

### 天气订阅与早晚报

| 指令 | 说明 |
| --- | --- |
| `#订阅天气 北京 07:30` | 按城市当地时间每日推送天气图片 |
| `#取消天气订阅` | 取消每日推送 |
| `#开启天气早报 07:00` | 设置并开启每日早报 |
| `#开启天气晚报 20:00` | 设置并开启每日晚报 |
| `#关闭天气早报` / `#关闭天气晚报` | 关闭对应简报 |

### 降水与气象预警提醒

| 指令 | 说明 |
| --- | --- |
| `#天气提醒` | 查看降雨、降雪提醒状态 |
| `#开启降雨提醒` / `#关闭降雨提醒` | 管理降雨提醒 |
| `#开启降雪提醒` / `#关闭降雪提醒` | 管理降雪提醒 |
| `#开启预警提醒` / `#关闭预警提醒` | 管理气象预警推送 |

## 兼容指令

早晚报继续兼容 `#设置天气早报` 和 `#设置天气晚报`。其他旧写法包括 `#查询天气`、`#逐小时天气`、`#24小时预报`、`#国内天气`、`#国外天气`、`#天气国内`、`#天气国外`、`#默认城市`、`#天气订阅`、`#退订天气`、`#天气数据源`、`#切换数据源`、`#添加天气API`。这些写法与推荐指令一样，可以省略开头的 `#`。

## 天气数据源

| 来源 | 需要 API Key | 主要特点 |
| --- | --- | --- |
| `bing`（MSN 天气） | 否 | 默认来源；读取 MSN 天气页面提供的预报与预警信息 |
| `open-meteo` | 否 | 天气预报及通用降水概率 |
| `weatherapi` | 是 | 提供独立降雨、降雪概率；也可用于气象预警 |

天气字段和地点覆盖范围因来源而异，并非所有来源都支持相同数据。详见[天气源字段兼容清单](docs/weather-source-compatibility.md)。

## 注意事项

- 不同数据源的天气字段和地点覆盖范围存在差异，区县等精确地点是否可用取决于地点搜索结果。
- 省、市级气象预警汇总可能无法覆盖所有下属地区；查询失败的地区会标记为未覆盖，不会当成无预警。
- 气象预警信息请以当地气象部门发布为准。
- 降雨提醒默认触发阈值为 **70%**；仅使用有效且能明确对应降雨的概率数据。
- WeatherAPI Key 请勿在群聊中公开。密钥配置方式见[高级配置](docs/configuration.md)。
- 部分群内设置需要群主或管理员权限；天气源、API 密钥和地点缓存维护仅限机器人主人。
